เบื่อไหมกับการโหลด PTU เป็นร้อย GB? บทความนี้จะสอนวิธีคัดลอกโฟลเดอร์เกม LIVE ทั้งหมดเพื่อสร้างเป็นโฟลเดอร์ PTU ซึ่งจะช่วยลดขนาดดาวน์โหลดเหลือแค่ไม่กี่ GB แถมยังเอาการตั้งค่าและ Keybinds ต่างๆ ตามมาด้วย! 🌌

> **Note:** แม้ในคู่มือนี้จะใช้คำว่า "PTU" เป็นหลัก แต่เทคนิคนี้สามารถใช้ได้กับเกมเวอร์ชั่นทดสอบอื่นๆ เช่น **ePTU** และ **TECH-PREVIEW** ได้เช่นกัน โดยเปลี่ยนชื่อโฟลเดอร์ปลายทางให้ถูกต้อง

---

## ขั้นตอนลดขนาดดาวน์โหลด PTU

### 1. ปิด RSI Launcher ให้สนิท

🚨 สำคัญมาก! คลิกขวาที่ไอคอนใน System Tray เลือก "Quit" และเช็คใน Task Manager (`Ctrl+Shift+Esc`) ว่าไม่มี `RSI Launcher.exe` ทำงานอยู่

![alt text](<img/Screenshot 2025-09-10 092357.jpg>)

### 2. คัดลอกและเปลี่ยนชื่อโฟลเดอร์ LIVE

   - ไปที่โฟลเดอร์ติดตั้งเกม (ปกติคือ `C:\Program Files\Roberts Space Industries\StarCitizen`)
   - คลิกขวาที่โฟลเดอร์ **`LIVE`** แล้วเลือก **"Copy (คัดลอก)"**
   - คลิกขวาในพื้นที่ว่าง แล้วเลือก **"Paste (วาง)"** เพื่อสร้างสำเนาของโฟลเดอร์ LIVE ขึ้นมา (จะได้โฟลเดอร์ชื่อ `LIVE - Copy`)
   - คลิกขวาที่โฟลเดอร์ `LIVE - Copy` ที่เพิ่งสร้างเสร็จ แล้วเลือก **"Rename (เปลี่ยนชื่อ)"**
   - เปลี่ยนชื่อเป็น **`PTU`** (หรือ `ePTU`/`TECH-PREVIEW` ตามที่คุณต้องการ)

    **โครงสร้างโฟลเดอร์สุดท้ายที่ควรจะเป็น:**
    ```
    Roberts Space Industries
    ├── RSI Launcher
    └── StarCitizen
        ├── LIVE
        ├── PTU
        └── TECH-PREVIEW
    ```

![alt text](<img/Screenshot 2025-09-10 094032.jpg>)

### 3. เปิด Launcher และอัปเดต
   - เปิด RSI Launcher ขึ้นมาใหม่
   - เปลี่ยนช่องจาก "LIVE" เป็น **"PTU"** (หรือช่องทางอื่นที่ต้องการ)
   - Launcher ควรจะแสดงปุ่ม **"UPDATE"** ให้กดได้เลย
      - **ถ้าไม่ขึ้น UPDATE** (ยังคงเป็น INSTALL หรือ DOWNLOAD): ให้ลองปิด-เปิด Launcher ใหม่อีกครั้ง หรือไปที่ **Settings (รูปเฟือง)** แล้วกด **"Verify files"**

![alt text](<img/Screenshot 2025-09-10 093215.jpg>)

Launcher จะตรวจสอบไฟล์และดาวน์โหลดเฉพาะส่วนต่างที่จำเป็นเท่านั้น ซึ่งจะลดขนาดดาวน์โหลดจาก 100+ GB เหลือเพียง 5-20 GB หรือน้อยกว่า! 🎉

![alt text](<img/Screenshot 2025-09-10 100928.png>)

## เคล็ดลับเพิ่มเติม

*   **จัดการพื้นที่:** เมื่อ PTU แพตช์นั้นๆ ออกสู่ LIVE แล้ว สามารถลบโฟลเดอร์ `PTU` ทิ้งได้เลยเพื่อคืนพื้นที่
*   **ติดตาม Patch Notes:** บางครั้ง CIG อาจเปลี่ยนโครงสร้างไฟล์ ซึ่งวิธีนี้อาจใช้ไม่ได้ผลชั่วคราว ให้ติดตามประกาศบน Spectrum เสมอ
*   **อัปเดต PTU ย่อย:** หากมี PTU build ย่อยออกมาใหม่ แค่กด "UPDATE" ใน Launcher ก็พอ ไม่ต้องคัดลอกไฟล์ใหม่ทั้งหมด

## สรุป: ประหยัดเวลา เข้าทดสอบได้เร็วกว่า!

เทคนิคคัดลอกโฟลเดอร์ `LIVE` นี้ช่วยประหยัดเวลาและอินเทอร์เน็ตได้อย่างมหาศาล แถมยังนำการตั้งค่าต่างๆ มาด้วย ทำให้การทดสอบ PTU ไม่ใช่เรื่องน่าเบื่ออีกต่อไป ขอให้สนุกกับการทดสอบฟีเจอร์ใหม่ๆ และช่วยกันรายงานบั๊กเพื่อพัฒนาเกมให้ดียิ่งขึ้น แล้วพบกันใน 'Verse ครับ! 👋
